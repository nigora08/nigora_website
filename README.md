# Nigora Ashrapova

Personal site for Nigora Ashrapova, mechanical engineering at Yale College, Class of 2030.

The site is static: `index.html`, `styles.css`, and `favicon.svg`. Open `index.html` in a browser, or from this folder:

```bash
python3 -m http.server 8000
```

To publish it with GitHub Pages, use the `main` branch and the repository root (`/`).
